### 2. 📊 **Amazon Sales Analytics** *(R)*

**What it does:**  
Statistical analysis of e-commerce sales drivers using multiple linear regression, ANOVA, and chi-square testing to move beyond correlation to causation.

**Key Findings:**
- Quantified impact of product category on sales volume (+/- 35% variation)
- Discovered inverse relationship between discount depth and profit margin
- Identified 3 pricing tiers with distinct customer behavior patterns

**Skills Demonstrated:**
- Multiple linear regression with diagnostic analysis
- One-way ANOVA for categorical comparisons
- Chi-square testing for independence
- Statistical assumption validation
- ggplot2 visualization

**Tools:** R, ggplot2, tidyverse, base stats  
**Datasets:** Amazon sales dataset (public)  
**[View Project →](/projects/amazon-sales-analytics)*

### 5. 📍 **Bayesian Data Analysis** *(R, JAGS/MCMC)*

**What it does:**  
Advanced hierarchical modeling using Bayesian methods to quantify uncertainty in regional performance and customer behavior, moving beyond point estimates to probability distributions.

**Key Findings:**
- Hierarchical logistic regression uncovered 3 previously undetected market segments
- Quantified regional performance variation with credible intervals
- Bayesian approach provides decision-makers confidence intervals (not just point estimates)
- CFO-ready communication of uncertainty in forecasting

**Skills Demonstrated:**
- Bayesian hierarchical modeling
- JAGS/MCMC (Markov Chain Monte Carlo)
- Prior specification & sensitivity analysis
- Posterior inference & interpretation
- Uncertainty quantification

**Tools:** R, JAGS, rjags, tidyverse, bayesplot  
**Methods:** Hierarchical logistic regression, posterior predictive checks  
**[View Project →](/projects/bayesian-analysis)*

## 💡 My Analytics Philosophy

Each project follows the same approach:

1. **Start with a business question** — not a dataset
2. **Combine rigor with clarity** — statistical validity + stakeholder communication
3. **Move from insight to action** — dashboards and reports that drive decisions
4. **Measure what matters** — focus on business impact, not raw scale

## 📖 How to Run These Projects

Each project folder contains:
- `README.md` — Project-specific overview and findings
- `notebooks/` — Jupyter/R Markdown files with full analysis
- `data/` — Sample datasets (or data sourcing instructions)
- `scripts/` — Reusable Python/R code
- `visualizations/` — Key charts and dashboards

**Prerequisites:**
```bash
# Python projects
pip install pandas numpy scikit-learn matplotlib seaborn jupyter

# R projects
install.packages(c("tidyverse", "ggplot2", "rjags"))

# For BI dashboards
# Power BI Desktop: https://powerbi.microsoft.com/en-us/desktop/
```
